Figma Match

Connect your Figma account

Sign in once with a read-only personal access token from your Figma account. Then you can open any frame you have access to and compare it with the page.

  1. Open Figma → Settings → Security.
  2. Under Personal access tokens, click Generate new token. Name it “Figma Match” and pick an expiry (90 days is a good default).
  3. Choose only these scopes: File content → Read-only and Current user → Read.
  4. Copy the token and paste it below.

How is my token protected?
  • It is encrypted with AES-256 before it is stored. The key can't be exported and is kept in this extension's own storage.
  • It is only ever sent to api.figma.com, in a request header. It is never sent to the pages you test.
  • If you untick “Keep me signed in”, the token stays in memory and is removed when Chrome closes.
  • Sign out deletes the token, the key and all cached designs. You can also revoke the token in Figma at any time.
